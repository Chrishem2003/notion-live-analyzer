# Phase 75 — Spatial Command Center

Creates the governed view-model for NEMA-AGORA's first spatial intelligence command center. It binds a validated AOI to baseline/comparison scenes, a Phase 74 spatial change map and optional human-review queue items.

The command center is evidence-oriented and read-only. It does not authorize enforcement, dispatch, regulatory conclusions, or autonomous action. It does not fabricate maps or satellite observations; live provider integration remains behind the acquisition boundary.
