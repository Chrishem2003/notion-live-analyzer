## 🚀 Getting Started

### 1. Load Your Data (Start Here)
Open the **📁 Data Studio** hub and use the **Ingestion** tab to:
- Upload a file (CSV, Excel, JSON, SPSS, SAS, STATA, Parquet)
- Or load a **sample dataset** from the gallery

The active dataset is shared across **all hubs** automatically. Once loaded,
you'll see its status in the sidebar (rows, columns, numeric/categorical counts).

### 2. Explore & Analyze
With data loaded, navigate to any analytical hub:
- **Statistics Studio** — run hypothesis tests
- **ML & Predictive Studio** — train models
- **Visualization Studio** — build charts & dashboards
- **AI & NLP Studio** — analyze text & generate insights

### 3. Publish & Share
- **Literature & Publishing** — format your results as APA, check citations
- **Collaboration & Portfolio** — manage projects and your academic portfolio

## 🔎 The Sidebar

Every page shares a consistent sidebar that provides:

- **Navigation Hub** — radio menu to switch between the 11 hubs
- **Commands Search** — type to find any tool across all hubs
- **Active Dataset** — live summary of your current data with clear/load actions
- **User Identity** — who's logged in, plus role

### Command Search
Type any tool keyword (e.g., `anova`, `sentiment`, `git`, `meta`) into the
**Command Search** box in the sidebar. It instantly lists matching tools so you
know which hub to visit.

---

## 🔄 Cross-Hub Data Pipeline

Your data flows seamlessly between hubs:

```
Data Studio (ingest) → Statistics (test) → ML (model) → Visualization (chart) → Publish (report)
```

All changes to the dataset (cleaning, transforms, feature engineering) are
stored in a **shared session state**, so every hub sees your latest version.

## 👤 Roles & Access

The platform supports **role-based access**:
- **Sovereign Administrator** — full access to all 11 hubs (including Admin & Security Center)
- **Data Analyst / Researcher** — access to all analytical hubs except Admin-only sections
