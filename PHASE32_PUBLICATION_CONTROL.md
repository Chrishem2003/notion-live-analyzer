# Phase 32 — Evaluation & Publication Control

Phase 32 adds a fail-closed gate for research/award documentation. It checks report identity, linked-claim minimum, provenance graph validity, source coverage, claim limitations, sample-size validity, and explicit human sign-off with rationale.

A passing decision is `APPROVED_FOR_PUBLICATION`, which means only that a human reviewer approved the bounded documentation artifact under this policy. The gate does not publish or externally submit content and does not establish environmental truth/impact, NEMA authorization, regulatory status, production approval, enforcement, emergency response or autonomous authority.

Missing evidence, broken lineage, unsupported claims, missing limitations, invalid sample sizes or missing sign-off produce `CONTROL_REQUIRED`.
