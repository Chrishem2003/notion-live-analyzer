# Phase 77 — Spatial Evidence API & Query Surface

Provides a provider-neutral, read-only query contract over validated spatial evidence records. Supports AOI, scene, candidate, review-status, temporal filtering and deterministic ordering/fingerprinting.

This is not a live public API and does not bypass governance. It exposes evidence records only; it cannot assert environmental truth, regulatory status, violation, enforcement, or emergency authority.
