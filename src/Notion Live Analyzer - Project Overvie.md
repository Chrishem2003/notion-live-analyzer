# Notion Live Analyzer - Project Overview

## What this app does:
- Connects to a Notion workspace to read database entries and pages.
- Analyzes text data and network traffic using Streamlit pages.

## Main Files:
- `modules/notion_sync.py`: Handles Notion API integration.
- `modules/ai_analyzer.py`: Runs data analysis routines.
- `pages/`: Streamlit UI tabs.
