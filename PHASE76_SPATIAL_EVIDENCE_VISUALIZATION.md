# Phase 76 — Spatial Evidence Visualization & Map Layers

Defines governed visualization layers for AOI boundaries, baseline/comparison index surfaces, grid-level change evidence and review-priority context.

The layer model is read-only and preserves source scene/map identity. It does not fabricate raster pixels, assert environmental truth, infer violations, or authorize enforcement. Live map rendering/provider connections remain integration work.
